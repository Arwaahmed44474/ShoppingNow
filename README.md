# 🛍️ ShoppingNow — Modern E-Commerce Web Application
FreshCart is an online shopping website where users can browse products by category, view product details, add items to a cart and wishlist, and create an account. The site supports Arabic and English and lets users switch between EGP, SAR and AED. It is fully responsive and deployed on Vercel.

Live demo: https://shopping-now-pearl.vercel.app/
