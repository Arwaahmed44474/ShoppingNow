An e-commerce website where users can browse products by category, view product details, add items to a cart and a wishlist, and create an account.

**Live demo:** https://shopping-now-pearl.vercel.app/

![Screenshot of the home page](./screenshot.png)
<img width="1897" height="896" alt="screenshot" src="https://github.com/user-attachments/assets/c6f1f4aa-a4fb-4f0e-919e-ef7219da4069" />

## Features
- Browse products by category
- Product details page
- Cart and wishlist
- Sign up and log in
- Responsive design for mobile and desktop

## Built with
Next.js, React, TypeScript, Tailwind CSS

## Run it on your computer
```bash
git clone https://github.com/Arwaahmed44474/ShoppingNow.git
cd ShoppingNow
npm install
npm run dev
```
Then open http://localhost:3000
